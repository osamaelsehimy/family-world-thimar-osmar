عالم الأسرة – ثمار OSMAR

اللعبة جاهزة للمشاركة من هذا الرابط:
https://osamaelsehimy.github.io/family-world-thimar-osmar/

افتح الرابط واضغط «ادخل جرّب اللعبة». لا تحتاج إلى حساب أو تثبيت لتبدأ اللعب، وتقدر تبعته لأي شخص.

اللعبة الحالية نسخة أولية: النقاط والتقدم مؤقتان ولا يتم حفظهما. إنشاء الحساب اختياري في الوقت الحالي، ويحتاج إلى تأكيد البريد الإلكتروني.

التثبيت على الكمبيوتر أو الهاتف:
- ويندوز: افتح الرابط في Chrome أو Edge واضغط رمز التثبيت بجانب شريط العنوان، أو اختر «تثبيت Family World» من قائمة المتصفح. سيظهر التطبيق بأيقونته في قائمة ابدأ.
- أندرويد: افتح الرابط في Chrome واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- آيفون أو آيباد: افتح الرابط في Safari، ثم «مشاركة» ثم «إضافة إلى الشاشة الرئيسية».

اللعبة تطبيق ويب قابل للتثبيت، وليست ملف APK أو EXE. بعد التثبيت تحتاج إلى الإنترنت لتشغيل الموقع وتسجيل الدخول.

اللعبة متاحة بالعربية والإنجليزية والصينية المبسطة. لا تدخل أسماء الأطفال الكاملة أو أرقامهم أو صورهم أو أي بيانات حساسة.

للتشغيل المحلي للمطورين: ثبّت Node.js 20، ثم نفّذ npm install وبعدها npm run dev. لنشر تحديث، ادفع التعديلات إلى فرع main؛ سيبني GitHub Pages الموقع تلقائيًا.
