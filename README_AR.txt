Family World – Thimar OSMAR
نسخة أولية بسيطة من OSMAR Ecosystems

تشمل سبعة عوالم، ألعابًا عائلية، شخصيات إرشادية، وواجهات بالعربية والإنجليزية والصينية المبسطة.

تشغيل محلي:
1. ثبّت Node.js 20 أو أحدث.
2. انسخ .env.example إلى .env.local وأضف رابط Supabase والمفتاح العام فقط.
3. نفّذ npm install ثم npm run dev.
4. لنسخة النشر استخدم npm run build وارفع مجلد dist إلى استضافة HTTPS.

بدون Supabase يقدر الزائر يدخل تجربة اللعبة بدون حساب، لكن التقدم لا يُحفظ والتسجيل بالبريد لا يعمل.
إعداد Supabase والبريد والتنبيهات موضح باختصار في README.md.
إشعار التسجيل يذهب فقط إلى Eng.osama.elsehimy@gmail.com بعد إعداد Resend وSupabase واختباره.

النشر إلى GitHub Pages يتم تلقائيًا من فرع main بعد اختيار GitHub Actions في Settings ثم Pages.
لا تدخل أسماء الأطفال أو صورهم أو بياناتهم الحساسة. نقاط اللعبة تجريبية وتُصفّر عند انتهاء الجلسة.
الشخصيات ممثلة برموز وواجهة أصلية؛ لم ننسخ صور المرجع لأن حقوق إعادة نشر الصور لم تتضح.
